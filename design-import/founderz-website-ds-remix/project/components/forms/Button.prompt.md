Founderz pill action button — use for every call-to-action; pick the variant to suit the surface it sits on.

```jsx
<Button variant="primary">Inscríbete hoy</Button>
<Button variant="third-outlined">Solicita información</Button>
<Button variant="second" as="a" href="#">Hablemos</Button>
```

Variants: `primary` (purple, on white) · `second` (white, on dark/purple) · `second-outlined` · `third` (black) · `third-outlined`. Sizes: `sm` `md` `lg`. Pass `icon` / `iconRight` for an inline SVG. Always pill-shaped, always sentence case.
