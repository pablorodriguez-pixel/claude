Founderz FAQ / syllabus accordion (card-d) — white card, chevron rotates 180° when open, smooth height animation.

```jsx
<Accordion question="¿Necesito conocimientos previos?" defaultOpen>
  No. El programa parte de cero y avanza hasta un nivel avanzado.
</Accordion>
```

Self-manages open state, or drive it with `open` + `onToggle`. Stack several inside a list for a full FAQ panel.
