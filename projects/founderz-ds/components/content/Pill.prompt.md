Founderz pill / badge — small rounded label for tags, categories and soft accents.

```jsx
<Pill>Nuevo</Pill>
<Pill uppercase>IA generativa</Pill>
<Pill variant="third">Curso</Pill>
```

`default` = lilac fill + purple text · `second` = black outline · `third` = white outline (on dark). Set `uppercase` for category pills.
