# Founderz Maqueta — Master Online IA para Creativos

Archivos descargados de: https://founderz.com/es/programa/master-online-ia-para-creativos/
Fecha: Mayo 2026

## Estructura

- `index.html` — HTML completo de la página de programa
- `css/program2026.css` — CSS principal de la LP de programa (el más importante)
- `css/main.css` — CSS global del theme de Founderz
- `css/vendor-slider.css` — CSS del slider/carrusel
- `js/Program2026.js` — JavaScript de la página de programa

## Stack

- WordPress + tema personalizado `founderz-theme`
- Vite (build tool) — clases tipo `vendor-slider-Dbi9JGEo`, `program2026-CpabL_HI`
- ACF (Advanced Custom Fields) para contenido editable
- CSS Variables para colores y tipografía
- JavaScript vanilla + jQuery para interactividad

## Notas para Claude

El CSS de `program2026.css` contiene toda la maquetación específica de las LPs de programa.
Busca las clases `.hero-`, `.module-`, `.pricing-`, `.faculty-`, `.sticky-` para entender los bloques principales.
