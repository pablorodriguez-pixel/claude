↻Cómo se mantiene
1. El equipo edita en Excel

El .xlsx vive en OneDrive. Estados, avances, gastos, KPIs e hitos se tocan ahí.

2. El agente sincroniza

Lee el Excel, reescribe los YAML del repo y hace commit. Cada sincronización queda en el histórico.

3. Esta página se regenera

build_web.py la reconstruye desde los mismos YAML, así que Excel y web nunca se contradicen.

Datos de ejemplo. Los 12 proyectos, 29 KPIs y 41 hitos de esta página son realistas y están atados al stack real (HubSpot, Make, GA4), pero están inventados. Sirven para ver el sistema funcionando y como plantilla de formato. Sustitúyelos por el portfolio real.
